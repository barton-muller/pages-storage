pages-storage example

A tiny app that keeps text files in a GitHub repo you own. Everything below runs in your browser. Source: pages-storage.

This page can read and write the repos you choose. Signing in installs a GitHub App on the repos you pick, and this page, or anyone who controls it, can then change any file in them. Use a test repo, not one you care about. After you sign in, one button creates a private one with a few sample files. You can remove the app from a repo at any time in your GitHub settings.

Real sign-in is off until you fill in CONFIG in this file.

Advanced: any git host with a token

No sign-in and no relay. Paste the address of a repo on GitHub, GitLab, Codeberg or a Forgejo or Gitea server, as you would for git clone, and a token that can write to it. The branch is the repo's default one unless you name it. The token stays in this tab only (session storage) and is gone when you close it. The server must allow this page's origin (CORS): GitHub, GitLab and Codeberg do. This example is limited to those three by its Content Security Policy.

The demo has a few made-up files that live only in this browser. Nothing is stored remotely. Clearing site data removes them.
